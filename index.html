Google Sign-In and Drive

Your Google account. Your Drive file.

Google integration is optional. When you choose to use it, QuoteCraft asks Google for the narrow drive.file permission. It can create a sync file and read or write only files that QuoteCraft creates or that you explicitly select with the Google Picker.

  1. Sign in on your device. Google shows its own account picker. Use any Google account that you control.
  2. Automatic setup on Android. QuoteCraft creates the sync file on the first phone and finds it automatically on another Android phone signed into the same account. On the web, select the same file once with the Picker.
  3. Sync across your devices. Open the same file on Android or the web with the same account. Changes are merged without sending your data to a QuoteCraft server.
